# MIMO-OFDM 通感共享物理层：第一阶段可验证基线

状态：**独立实现且可运行的简化物理层**。暂未接入原有的异步 World Model / VoI 决策主循环；不得把它写成完成了端到端无线世界模型。目标是为后续自主研究提供可信的可比较观测来源。

## 1. 系统拓扑与资源

- 一个固定基站，**2 个发射天线**，向具备 **4 个接收天线**的终端发送**2 条独立 QPSK 数据流**；这是空间复用的 MIMO 下行，而非只把单流波束形成误称 MIMO。
- 同一基站的 **8 天线单站雷达接收阵列**接收来自一个运动点目标和一个静态杂波点的回波。数据和探测符号**共用同一个 OFDM 发射网格**，不生成第二套无关的波形。两种接收机的收发链路和时钟都作理想化处理。
- 起始 2 个 OFDM 符号分别从两个发射天线发送正交训练导频。数据符号承载独立双流 QPSK；探测专用符号沿预先配置的扇区方向发射相干波束。每个有效资源元素的**总发射平均能量保持为 1**；探测符号占比增加必然挤占数据符号。
- 通信用户接收机**只用有噪训练导频估计 CSI**，利用 MMSE 线性检测解调数据；回波处理器知道本基站发出的全部数据和导频，进行角度、距离、慢时间多普勒联合匹配处理，并过滤零多普勒单元。探测器**没有获得真实目标位置和速度**。
- 通信链路包含 LOS、两个静态反射体和**同一个运动散射体**；雷达链路包含该散射体和一个静态杂波。目标角度/位置、速度改变会改变两种观测，因而是共用的物理环境变量。

## 2. 明确的信号约定

设 \(X_{m}[s,k]\) 为符号 \(s\)、子载波 \(k\)、发射天线 \(m\) 的复 QPSK 发射符号，\(\Delta f\) 是子载波间隔，\(T_r\) 是 OFDM 脉冲间隔。

通信链路：

\[
Y^{\mathrm{com}}_{r}[s,k] = \sum_m H_{rm}[s,k] X_m[s,k] + W_r[s,k],
\]

其中 CSI \(H\) 来自 LOS/静态反射/运动散射路径之和，频率项为 \(\exp(-j2\pi f_k\tau_\ell)\)，运动散射路径还随慢时间转相。通信有噪导频估计值 \(\widehat H\) 用于 MMSE 检测，故**不是完美 CSI / oracle 解码**。

单站回波：

\[
Y^{\mathrm{rad}}_r[s,k] = \alpha a_r(\theta)
\left(\sum_m a_m^*(\theta) X_m[s,k]\right)
\exp(-j2\pi f_k(2R/c))\exp(j2\pi f_D sT_r) + C_r[s,k] + N_r[s,k].
\]

此处定义径向速度**远离雷达为正**，所以 \(f_D=-2f_c v_r/c\)。\(C_r\) 为静态杂波项。接收机对候选角进行阵列匹配，对传输波形做相干匹配，再依次做慢时间 FFT 和频率域 IFFT，寻找距离/角度/多普勒峰值。它只在给定 CP 距离范围和非零多普勒网格内搜索。

本基线**未实现**载波内多普勒 ICI、相位噪声、CFO、ICI 消除、帧不同步、多目标数据关联、真正的 RCS 频散、材料反演、射线追踪、信道编码或硬件链路预算。分数时延使用理想频域相位响应；CP 样本整数时延额外通过独立时域延迟测试验证。传播路径的复增益多数取固定演示系数而非校准测量，目标回波采用明确的 \(R^{-2}\) 电压幅度比例示例。

## 3. 数值分辨率与验证

默认 \(N_{\mathrm{FFT}}=128\)，子载波间隔 500 kHz，采样率 64 MHz、CP 24 样本、64 符号、PRI 0.5 ms，载频 24 GHz。

- 范围采样栅格约 \(c/(2f_s)=2.34\) m；**有效带宽对应的物理距离分辨率更粗**，约 \(c/(2B_\mathrm{occupied})\)。不能把栅格误当精度保证。
- 单站目标回波需落在 CP 对应的约 56.2 m 范围内；本实验的参考目标约 18.75 m。
- 速度 FFT 栅格 \(c/(2f_c N_s T_r)\)，约 0.195 m/s。超出采样定理的多普勒或移动太快需要新的模型。
- 不同资源占比的相同随机种子共用底层运动状态、LOS/散射路径和独立噪声流。逐 seed 记录 BER、目标误差、载荷比特和跟踪单元是否正确。

代码测试包含 FFT/CP 往返、**独立时域整数延迟与频域相位一致性**、QPSK 正反映射、发射能量、有限导频的 MIMO 检测、通信 SNR 敏感性、回波三参数恢复、移动散射点对通信和雷达链路的共同影响、对准与错向波束对比，以及输入边界、输出不可覆盖和可复现性。

**评估指标解释：**

- `ber` 是无纠错 QPSK 位错误率；`nominal_raw_payload_rate_bps` 是协议假设下的原始载荷比特率，不是无线 Shannon 容量，也不是完整系统的实际吞吐量。
- `correct_bit_rate_proxy_bps` 仅为正确解码比特数／模拟帧时长，不能作为**可靠传输 goodput**，没有 ARQ、FEC、MAC 帧或吞吐确认。
- `matched_peak_energy` 是搜索峰值的平方幅度，不是已标定的检测概率或雷达 SNR；尤其在高噪声条件下，最大值筛选有正偏差。
- `target_cell_detection_rate` 使用了**评测端才有的真实目标状态**，检验估计是否落入事前设定的距离/角度/速度容差，不能把它当目标“材质/类别识别率”。

## 4. 运行与输出

在项目已安装的隔离环境内，执行：

```bash
bash scripts/env.sh python scripts/phy_sweep.py \
  --out runs/phy-mimo-ofdm-1 --trials 16 \
  --fractions 0,0.2,0.4 --radar-snr-db -35
```

每个输出目录包含：`manifest.json`（参数、版本、源码哈希、结果与假设）、`episodes.csv`（每轨迹数据）、`summary.csv`（各探测占比的均值）。目录已存在时拒绝覆盖。

`--radar-snr-db -35` 是为了让噪声应力测试能区分方案，不是现实硬件标定过的 dBm／链路 SNR。

**当前任务与原研究系统的交接契约（尚未执行集成）：**先把 `Y^{rad}` 经检测/估计处理成带方差与时间戳的范围／角度／速度测量，再替换 `ToyScene` 的无线观测；随后令通信奖励来自此处的 BER/占空及后续可实现速率，而不是旧 AWGN 代理。要继续到 ML 驱动的 VoI，必须在不同探测动作下生成可信配对观测，避免观察动作泄漏目标真值。

## 5. 在 MATLAB 上做什么？

两条互补路线：

1. **官方完整版示例**：MathWorks 官方例子 [Integrated Sensing and Communication II: Communication-Centric Approach Using MIMO-OFDM](https://www.mathworks.com/help/phased/ug/integrated-sensing-and-communication-2-communication-centric-approach-using-mimo-ofdm.html)，需要 Communications Toolbox 和 Phased Array System Toolbox；示例采用**双站**接收感知，与本仓库第一阶段的**单站**回波拓扑不同，不能直接逐数字对比。
2. **独立 Base MATLAB 数学自检**：仓库 `scripts/matlab_phy_smoke.m` 只用基础 FFT、矩阵和 CSV，检验 CP 时域延迟与多普勒/角度匹配的离散模型；它没有用 Python 的随机种子或执行全部 MIMO 接收机，**尚未在本轮 MATLAB 环境实际执行**。Mac 进入仓库后可运行：

```matlab
addpath('scripts');
matlab_phy_smoke('runs/phy-mimo-ofdm-1/summary.csv');
```

数学自检通过不代表两种实现已完成逐样本一致性验证。以后要对比，应固定信号文件、所有随机种子、归一化、FFT/CP、阵列坐标及时间基准。

## 6. World Model 下一阶段的正确位置

这份 PHY 输出物理观测，**不是自身具备物体材质推理的 World Model**。未来将表示多个可反驳的假设，例如“反射来自不同材料、形状或遮挡方式”，并在可观测性条件允许时以多时刻、多角度、频率/极化和视觉证据更新；证据不足必须保持未知，不能由网络填补“想象的真值”。第一步先研究显式反射/路径状态和不确定性，接入到已有结构化动态表示与动作条件观测头。
