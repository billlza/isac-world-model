# 多假设预测记忆：第一轮闭环基线

这轮新引入 `src/isac_wm/predictive_belief.py`，是**可验证的模型驱动信念更新模块**，不是已经训练完成的深度语义 World Model，也不是人类式通用推理。

## 三个闭环环节

1. **跨时刻有限记忆**：每个 RF/视觉观测必须携带唯一证据 ID、采集时刻和可用时刻；未来观测拒绝访问，过时 RF 不能覆盖新证据，记忆长度有上限（超出 ID 总量则要求开启新 episode）。保留观测来源及更新/拒绝原因。
2. **动作条件反事实预测**：同时保留 `static_reflector` 与 `moving_scatterer` 两个动力学解释；对相同未来时刻分别预测距离和径向速度的均值及假定误差；对 `skip / quick / precise` 报告不同测量噪声、资源占比与理想最早可用时刻。
3. **基于真实到达证据的纠错**：对每个解释计算观测创新，采用高斯假设下的可审计似然并更新模型内状态与相对权重；严重离群点通过创新门控拒绝，视觉方位冲突单列记录。不允许利用仿真隐藏真值修正。

## 明确边界

- 这两个假设是**运动类型**，不是材质、物体语义或可靠的身份匹配；物体材料、形状和身份始终保持 unknown。
- 高斯观测误差、过程噪声及门控阈值都属于研究假设，不是经过实测校准的置信保证。
- `forecast_actions` 使用旧 `ToyScene` 记录的 quick/precise 噪声和理想传感时延，尚未从新 MIMO-OFDM 信号链路自动估计这些值。因此当前并非完整物理 ISAC 闭环。
- 尚无可跨帧的真实多目标 RF 路径关联或频率相关材质散射模型。临时把不同目标的观测关联到一个轨迹，可能导致错误更新；实际部署前必须强化数据关联与拒绝条件。
- 只在简化单目标运动模型下判断距离、径向速度；角度随时间的变化保持 unknown，不应偷偷假设方位静止。
- 这种有限模型集仍是传统 Bayesian/IMM 风格的**强基线**；后续原创学习机制需使用独立训练集，比较可学习转移/观测模型、反事实价值和强滤波基线，验证真正额外贡献。

## 测试

`python -m pytest tests/test_predictive_belief.py` 覆盖未来信息泄露、重复 ID、记忆容量、动态更新、离群点拒绝、视觉矛盾、乱序和动作条件预测。新增代码不改现有训练流程与 CI 配置。

下一轮应把 PHY `Y^{rad}` 的距离/角度/速度观测及噪声估计绑定到时间轴，并训练独立的多模态潜状态转移/观测预测头。在真实或信号级验证场景下报告校准与失效，而不是预设神经模型胜出。
