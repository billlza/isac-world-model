# H200：模型容量与训练数据量对照

## 本轮要回答的问题

前一轮 `19344575` 的结果支持两个具体结论：A96 的初始化 7 能利用重新到达的视觉观测降低恢复误差；初始化 11 的表现明显更差，换另一组 96 条训练轨迹没有消除差距。本轮同时增加训练时长、模型容量和可用轨迹量，用完整对照区分它们的作用。

主问题是：在相同参数更新次数、相同验证集和选优次数下，增加隐藏维度或独立训练轨迹，能否提高恢复、未来预测和两个初始化之间的一致性？本轮从随机初始化开始，不续训之前的检查点，不使用预训练权重。

## 固定实验设计

| 因素 | 水平 |
| --- | --- |
| 架构 | `structured-attention`，feature 48，记忆 16，attention heads 4 |
| 隐藏维度 | 96 / 512 |
| 参数量 | 172,246 / 3,883,798（约 0.172M / 3.884M） |
| 独立训练轨迹 | 96 / 1,536，前 96 条严格包含在大集合中 |
| 初始化 | 7 / 11 |
| 参数更新 | 每组固定 1,536 次，batch 8 |
| Epoch | 小数据 128；大数据 8 |
| 验证集 | 所有组共用 192 条轨迹 |
| 验证与选优 | 每 96 次更新验证一次，共 16 次，以当前位置 RMSE 选最优检查点 |
| 优化器 | 现有 AdamW，学习率 0.001，weight decay 0.0001，梯度范数上限 1 |
| 小批次顺序 RNG | 37；数据长度不同时，同一 RNG 种子不代表批次内容相同 |
| 精度 | 延续现有 FP32 路径，未在本轮引入混合精度作为额外因素 |
| 场景 | 64 ticks，dt 0.1 秒，10 m 房间，原有异步视觉/RF 接口 |
| 测试 | 新的 24 对直行/转向轨迹，共 48 个案例 |

共有 8 组，串行使用一张完整 H200。A512 约为 A96 的 22.55 倍参数量，约 0.003884B。旧的 0.3 秒 CUDA 试运行和本轮实验预算属于不同阶段，不用于推算本轮的训练结论。

### 轨迹划分

- 训练：`700000..700095` / `700000..701535`。
- 公共验证：`74611000..74611191`。
- 新测试：`95871000..95871023`；两个条件按同一轨迹 seed 配对。
- 旧测试 `93621000..93621023` 和已分析的 `94761000..94761023` 不参与本轮选优。
- CI 仅使用 `81700000`、`81710000`、`81720000` 起始的独立开发集合。

先训练并冻结全部 8 个验证集最优检查点及 SHA-256，然后计算测试结果。相同宽度、相同初始化的两种数据量必须有相同初始权重指纹。测试轨迹与模型的训练/验证 provenance 必须无交集。

### 为什么按更新次数控制

如果两种数据量都训练 16 epochs，1,536 条数据组会多获得 16 倍的参数更新；如果每 epoch 验证一次，选优频次又会不同。本轮直接固定更新数和验证间隔。大数据每个 epoch 中途也会验证，小数据每 8 epochs 验证，均在更新 96、192、…、1,536 处选优。

这是一项固定优化预算的实验。它估计在该预算下增加数据或容量的效果，不把“更大模型在任意训练预算下都更好”作为默认结论。

## 观测与内部诊断

诊断开关只复制本次前向计算中的数值，不改变模型输入、预测、权重或后续状态。代码测试比较开关前后的逐步输出和模型指纹。

每次真正到达且被 SnapshotBuffer 接纳的新观测记录：

- capture / available / decision / estimated-state 时间与观测 ID。
- 视觉位置编码在**拍摄时刻**的误差，避免把传输时延误认为视觉识别误差。
- 视觉热图熵、学习出的观测方差，以及叠加熵项后的总方差。
- 视觉和 RF 各自的 innovation、innovation covariance、增益与实际状态修正。
- 修正前后位置误差、全部新观测和恢复窗口内新观测的独立统计。

用于评分的真实状态在模型前向之后才读取。没有新观测的 tick 不伪装成再次获得视觉证据。诊断回放时间包含复制与记录开销，不能当成无诊断推理延迟。

## 评估与解释

主要指标保持上一轮的 1 秒恢复窗口位置误差积分（m·s）、3 次连续低于 0.25 m 的恢复确认时间、窗口末端复发，以及 0.3 秒因果未来位置预测。预测起点为 tick 5..60，预测目标为 tick 8..63。

所有模型都接收同一条已交付观测序列；KF 和门控 IMM 也报告恢复和未来预测。对比包括每个具体模型、同一宽度/数据量下两个初始化的等权平均、宽度效应、数据量效应、二者交互和初始化差异。输出保留全部结果，不只导出最好的初始化。

置信区间按测试轨迹配对 bootstrap（4,000 次）计算，单位随指标记录。该区间条件于初始化 7 和 11，不代表对所有可能训练随机种子的总体不确定性；时间点不是独立重复实验。
