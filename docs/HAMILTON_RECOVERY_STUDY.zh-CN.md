# 单卡 H200：配对的运动状态恢复实验

起点是已在 Hamilton 上完成的研究提交 `46ef343` 和作业 `19340270`。本轮是新的训练、验证、测试分割和运行目录，不从那个 pilot 继续，也不覆盖它的结果。学校 CUDA 模块的兼容性记录与仓库默认的 CPU 软件锁分开。

## 科学问题

遮挡期间目标改变运动后，等到相机给出新位置，显式事件记忆能否缩短恢复时间？保留对照方向：历史信息可能帮助缺测段外推，也可能在证据改变后拖慢纠错。算法看不到场景标签或未来真值。真实部署的波形测量接口、传感设备试验和在线改权重的“再学习”属于另外的实验。

在隐藏维度 96 和 192 上，分别比较两个从随机初始化开始的 ToyScene 估计器：`structured` 和 `structured-attention`。两者都有视觉/RF编码器、GRU状态、显式运动状态和协方差；后者另有有限事件库和四头检索、投影与前馈层。因此两模型之差反映整个增量架构，参数量并不相等。相同训练种子并不意味着两种架构所有初始张量相同。训练仍使用标准 ToyScene 随机采集日程；受控恢复挑战用于独立测试。在合成任务上，考察新证据前后的估计与预测，不训练聊天模型或自主采集策略。

## 预先固定的比较

在每个训练种子（7、11、13）下，四个组合用相同的 96 条训练轨迹、12 条验证轨迹，每条 64 步；训练 16 个 epoch，batch 8，学习率 0.001。注意力配置在两种宽度下均为 4 个头、16 个事件槽，编码维度固定为 48。每个模型有同样的 192 次优化更新，宽模型的计算量不同；结论是等数据和更新数下的比较。每个配置用自己的最低验证定位 RMSE 的检查点评估。正式恢复挑战只用于报告，开发集不会排进这组种子。

| 结构 | 隐藏宽 96 | 隐藏宽 192 |
|---|---:|---:|
| structured | 91,990 | 290,710 |
| structured-attention | 172,246 | 598,678 |

参数量取自真实实例。主问题：在相同宽度下，显式事件记忆对恢复误差的作用。规模问题：在相同架构下，宽度增大后误差变化多少；附报两类架构受宽度影响的差异。两种架构同宽并非等参数。针对缺测推演和恢复纠错分别报告，不把当前定位 RMSE 当预报误差或恢复时间。

### 已完成的小样本开发试验

[开发作业原始记录](https://github.com/billlza/isac-world-model/actions/runs/41719977311/job/126209869648) 和同目录 `recovery_scale_development.json`：CPU，独立开发训练种子 19，24 条普通训练轨迹，8 条验证轨迹，每条 64 步，两轮共 6 次更新。第 2 轮当前二维定位 RMSE（米）：structured 96 / 192 为 0.64267 / 0.61827；注意力 96 / 192 为 0.47071 / 1.07744。这个结果既不能替代 Hamilton 训练，也不能选择正式测试数据。它给出一个明确反例：在这组相同输入和更新数的早期训练中，加宽并非总带来更低的验证误差。

## 单独使用训练好的模型

从仓库根目录用已有解释器运行：

```bash
PYTHONPATH=src "$ISAC_PYTHON" scripts/forecast_from_prefix.py \
  --checkpoint /absolute/path/to/model.pt --out forecast-new.json --radio-queries
```

每条演示轨迹只从一段已经可用的合成相机/RF前缀形成 belief，然后停止接收观测。从同一个 belief 分别查询 0.1、0.3、1.0 秒的运动状态及协方差。快速和精细采集的 RF 特征均值在截止时刻作假设查询，不会把预测当成真实回波写回，也不实际控制设备。标准训练的未来预测监督是 0.3 秒；1 秒结果属于外推。这里没有用真实未来对这些演示值做准确率评分，输出也不是新场景视频。若要自主行动，后续需额外定义动作、目标、代价、策略和闭环试验。

## 向实验室申请设备时

第一阶段建议先借一套可重复采集的数据链路：能导出带硬件时间戳的复数 I/Q 或 CSI 的射频设备、同步或可测时差的相机、可重复改变运动方向的目标、可移动遮挡物，以及不进入模型输入的独立位置真值（例如已有的动捕系统）。写清每条测量的采集时间、送达时间、动作、包号与丢包。若要验证同波形通信与雷达感知两项性能，同时保留通信接收端数据与感知回波。先从静止目标时钟/坐标对齐和一条运动路线开始，再按距离、带宽、角分辨率和实验室库存确定型号。支持外参的设备可采用公共频率参考和同步触发，具体接口以所借设备文档为准；示例：[USRP 同步手册](https://files.ettus.com/manual/page_sync.html)。
